# 跨链套利 Dashboard（只读展示页）

> 在线页面：https://ahaxin.github.io/crosschain-arb-dashboard/

监控同一资产在 65 条 EVM 主网链上的价格差异，并用 Li.Fi `advanced/routes`
**核实真实可成交价**，算出扣掉滑点与桥费后的**有效价差**。

## 这个仓库是什么

只是一个**静态展示页 + 行情数据**：

| 文件 | 说明 |
|---|---|
| `index.html` | 静态 Dashboard（无后端） |
| `scan.json` | 扫描结果，由 GitHub Actions 定时更新 |

扫描器源码、告警逻辑、风控文档在私有仓库中，不在此处。

## 怎么看这个页面

| 列/标签 | 含义 |
|---|---|
| 价差 | Li.Fi 参考价算出的**毛价差**，**会虚高** |
| 🟡 实际 | 用真实报价算出的**有效价差**（已含滑点+桥费），这才是能赚到的 |
| 滑点 | 毛价差 − 有效价差，薄流动性的真相 |
| 🟢 可执行 | 有可用跨链路由 **且** 有效价差 ≥0.5%（按 $1000 估算） |
| 🔴 无路由 | Jumper/Li.Fi 上没有可用桥接路径，**无法执行** |
| 🔴 流动性不足 | 有路由但有效价差 <0.5%，滑点吃掉了价差 |

**关键认知**：毛价差 10% 的小币，滑点往往也在 10% 左右，正好把价差吃穿。
勾选「仅可执行」才是真正值得看的机会。

## ⚠️ 免责声明

数据仅供参考，**不构成投资建议**。跨链套利存在桥合约风险、流动性风险、
价格波动风险。下单前必须在 Jumper 等桥的界面确认实际报价与目标链卖出深度。
